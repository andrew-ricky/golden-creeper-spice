# 🌿 Golden Creeper Spice Garden & Herbal Web Application

An e-commerce and informational web application built for **Golden Creeper Spice Garden**, showcasing authentic Sri Lankan spices, natural herbal remedies, and products with a seamless shopping experience and user authentication.

---

## ✨ Features

* **Product Catalog & Management:** Browse a wide variety of authentic spices and herbal products
* **Shopping Cart System:** Add items, update quantities, calculate grand totals, and manage local storage cart state
* **User Authentication:** Secure user login and registration powered by **Supabase Auth**
* **Responsive Design:** Optimized layout for mobile, tablet, and desktop screens using custom CSS media queries
* **Optimized Performance:** Fast-loading pages with lightweight structure and modern image rendering.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Variables & Flexbox/Grid), JavaScript.
* **Backend & Database:** Supabase (PostgreSQL & Authentication).
* **Hosting / Deployment:** GitHub Pages / Netlify / Vercel
